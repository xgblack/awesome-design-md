[+] HOW TO READ A PATCH

        

          01 / CONTEXT
          
没有前缀的行是上下文。它们帮助你理解变化发生的位置，不是需要执行的指令。

        

        

          02 / ADDITIONS
          
以 + 开头的行是新增。选择“仅新增”，暂时把注意力留给修复后的路径。

        

        

          03 / DELETIONS
          
以 − 开头的行是删除。前后两面都读过，才能判断修复是否完整。

        

      

      

        
[?] QUESTIONS

        
会执行补丁吗？

        
不会。这里不连接仓库，也不解释代码。所有内容作为文本显示。

        
未知格式怎么处理？

        
broken.patch 故意保留一个格式错误，阅读器会显示原因而不是伪造差异。

        
数据会保留吗？

        
所有选择都只在当前页面。刷新后回到默认样例。
