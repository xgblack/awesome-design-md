# 风格示例（后续制作）

此目录预留给真实的独立示例，本轮不制作样例页面。

后续每个风格使用与 `design-md/` 相同的目录标识，例如 `examples/cursor/`、`examples/linear.app/`。示例关联原始 `design-md/<id>/DESIGN.md`，不手工复制维护另一份规范。

在接入首个真实示例时再实现预览注册、隔离容器、视口切换、真实截图和页面对比。必须完成主要交互、窄屏适配和规范核对后，才能将状态从“待制作”改为“可用”。所有未完成项继续保持可查找、可阅读的规范入口。

共同展示场景、素材替代及每种示例的实现方式仍待后续确认；不把外层应用的字体、组件或规范封面当作具体风格的设计表达。
