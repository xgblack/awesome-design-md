# Design Atlas

`awesome-design-md` 的独立设计语言工作台，当前包含84种风格的独立可操作示例、真实缩略图及20维筛选。Vue 3 + TypeScript + **Vite+ 1.7（内含 Vite 8）**；无需后端、账号或在线 AI。

## 使用

```sh
cd preview-app
vp install --frozen-lockfile
vp dev
```

需要全局 `vp` 和 `^22.18.0 || ^24.11.0 || >=26.0.0` 的 Node.js。全局 CLI 会调用固定的项目工具链。默认仅监听本机；指定端口可用 `vp dev --port 5178 --strictPort`。

```sh
vp run build
vp preview
```

`vp run build` **先执行完整 `vue-tsc` 检查**，再将工作台和全部独立 HTML 入口一起打包。直接 `vp build` 仅打包，不能替代 Vue 模板类型检查。npm 是声明的底层包管理器，`package-lock.json` 是唯一锁文件。

完整部署 `dist/` 到静态站点，可置于子目录。相对资源与 Hash 路由无需服务端 SPA 回退；不要只上传工作台的 `index.html`，也要包含 `examples/`、`assets/`、原文和许可证。示例不依赖开发服务器来运行 TypeScript。

## 浏览与比较

- 按实际 `design-md/*/DESIGN.md` 收录，不以 README、YAML 解析状态或是否已有示例决定收录。当前规范规模为 84 种；新增源文但没有示例时自动进入待制作。
- 图库只懒加载真实首屏截图，不同时创建全部 iframe。待制作使用明确标识的规范封面；截图失败、制作未完成和单次页面加载失败分别显示。
- 详情提供可操作独立页面，桌面 **1440×900** / 手机 **390×844** 的实际布局视口、放大与独立打开。容器按可用空间缩放，不把窄屏适配等同于缩小桌面布局。
- 最多三项页面视觉对比，也可切到规范信息对照。手机端只挂载当前候选。每页在对应规范原主题内选择最佳场景，同类主题相近、具体内容可不同，因此是视觉语言参考，**不是同内容 A/B 测试**。
- 原始 Markdown 按需加载，支持阅读/源码/原样下载/复制。渲染禁用原始 HTML、远程文档图片及不安全链接；复制失败不会假称成功。
- 收藏仅在当前浏览器保存，失败明确提示；所有示例业务输入默认只在其文档内存中保存。

## 六组、20 维筛选

| 分组       | 维度                                                         |
| ---------- | ------------------------------------------------------------ |
| 气质与配色 | 视觉气质、明暗构成、界面色温、界面彩度、主要强调色、背景处理 |
| 构图与字阶 | 主体版式、信息密度、字体性格、主标题尺度、主标题字重         |
| 组件与层次 | 组件形状、层次手法                                           |
| 素材与动态 | 主要视觉载体、动效程度                                       |
| 用途与能力 | 页面场景、目录领域、已有示例交互                             |
| 可用状态   | 制作状态、已验证视口                                         |

**按规范特点**使用 `src/data/curation.ts` 的本地归纳与出处，不声称这些是上游原生标签。**按示例页面**只显示验收为可用的示例，使用各页 `example.json` 中的实际特征，不以规范值补齐未知。目录领域始终按原规范分析对象归类；交互和已验证视口始终来自示例验收。

同维多选“或”，跨维及关键词/收藏范围“且”。信息密度、主标题尺度、主标题字重、目录领域采用单选。选项数量忽略自身维度、保留其他约束；多标签数量不能相加作为总量。未知不等于没有：不选择该维度时不丢条目，选择后未知不匹配。零数量未选项不可新增选择，已选项仍可移除。

常用五组默认展开，其余按主题折叠；手机筛选先编辑草稿，取消不生效，应用才写入 URL。旧 `colors=warm,gradient` 仍表示“暖色**或**渐变”，不会错误迁移成两个新维度的“且”。所有条件、筛选依据、视口和对比模式均可恢复；推荐顺序是显式编辑顺序，不是风格评分或热度。

详情可展开规范依据、示例观察、字体替代和素材来源。原文首次出现的五个色值只作摘录，不自动推断主题或主强调色。

## 验证与截图

```sh
vp check
vp test
vp run check:catalog
vp run check:examples
vp run build
vp run test:examples
```

单元测试只运行 `tests/**/*.test.ts`。Playwright 的独立用例覆盖各页核心操作，通用检查覆盖就绪信号、本地资源、页面错误及 1440 / 390 / 320px 布局边界；工作台用例另覆盖筛选草稿、原文下载、比较、设备切换和加载失败恢复。默认使用本机 Chrome，默认启动/复用 4173 端口的开发服务；没有 Chrome 时需按 Playwright 配置安装可用浏览器并调整 `channel`。

用静态生产服务检验时，传入其完整基址（子目录末尾保留 `/`）：

```sh
ATLAS_BASE_URL=http://127.0.0.1:4175/nested/atlas/ vp run test:examples
```

截图前先构建并启动 `vp preview --port 4173 --strictPort`（不能与同端口开发服务同时启动）。随后：

```sh
vp run capture:examples
# 或仅更新指定页面
vp run capture:examples cursor airbnb dell-1996
# 最后重新构建，以纳入更新后的缩略图
vp run build
```

`capture:examples` 从真实页面等待字体与图片就绪，触发懒加载、回到顶部，捕获每页两端全页图到忽略目录 `.screenshots/examples/`，另将桌面首屏生成 `examples/<slug>/thumbnail.webp`。不是将整张长图压成细条，也不把截图文件存在当成设计验收。截图基址同样可用 `ATLAS_BASE_URL` 指定。

浏览器模拟和自动检查不代表真机/全浏览器无障碍认证。

## 独立示例与资源

内容以原规范语境为准：汽车/航天/硬件展示产品与技术，开发/AI展示平台任务，协作与金融保留对应工作语境；不统一文案，也不为差异化随意改成无关行业。

每个示例为独立 HTML/CSS/TypeScript 文档。共享部分仅有字体、有限摄影资产和非视觉就绪通知，不存在统一 Header/Hero/Card 模板来批量换色。示例不会修改原始规范、父文档或外层收藏。

**同源 iframe 是文档和样式隔离，不是恶意代码沙箱。** 本工程仅运行仓库内审阅过的示例，不支持执行上传/粘贴的任意 HTML，不嵌入品牌在线官网，也不加载第三方业务脚本。

照片、原创向量、合成媒体、许可朗读样本和开源近似字体随项目本地加载。每页元数据记录实际来源及替代；共享摄影见 `examples/_shared/photos/sources.json`，NASA发射资料图保留具体任务与署名，不当作虚构产品实拍；LibriVox预录朗读见 `examples/_shared/audio/sources.json`，不声称AI生成或音色克隆。来源记录与字体完整许可证随生产资源保留在 `public/licenses/`。Pinterest 等独有资源的许可在本页目录及详情中说明。使用摄影不表示图中人物/品牌为虚构产品代言。示例不是品牌官方页面，也不提供真实交易、AI 推理或媒体生成服务。

新增/维护方式见 [examples/README.md](examples/README.md)。
